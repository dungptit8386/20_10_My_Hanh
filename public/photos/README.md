# 📸 Thả ảnh kỷ niệm vào đây

Copy ảnh của bạn vào thư mục này và đổi tên chính xác thành:

- `us-1.jpg`
- `us-2.jpg`
- `us-3.jpg`
- `us-4.jpg`

(Đuôi `.png` cũng được — nếu dùng `.png`, nhớ sửa `src` trong `src/data/messages.ts`.)

Chưa có ảnh cũng không sao: ô trống sẽ tự hiện khung dễ thương, website vẫn đẹp.
Sau khi thả ảnh vào, chạy `npm run dev` (xem ngay) hoặc `npm run build` rồi deploy lại.
